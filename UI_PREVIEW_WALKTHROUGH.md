---

## 1. Overview & Quick Start

AcademicOS is a local-first, AI-powered academic operating system designed natively for iOS. To enable high-fidelity visual inspection of the interface and workflows directly on Windows without modifying the native Swift/SwiftUI application or touching SQLite databases, a dedicated companion environment has been created in the `UI-Preview/` directory.

### Launching & Viewing
The preview server runs as a zero-dependency Node.js HTTP service:
```bash
# Served from UI-Preview/server.js
http://localhost:5050
```

### Studio Toolbar Controls
At the top of the browser window, a developer studio bar provides quick controls:
1. **Jump Screen Dropdown:** Instant navigation to any of the 16 core application states.
2. **Light / Dark Mode Toggle:** Switch seamlessly between Apple-inspired dark mode (deep zinc `#09090B`) and light mode (`#F8FAFC`).
3. **Simulate Offline Toggle:** Instantly simulate network loss, triggering the native offline banner, routing indicators, and fallback states.
4. **Bezel Toggle:** Toggle the realistic titanium iPhone 16 Pro frame on or off.

## 3. Technology & Architecture Notes

- **Zero iOS Modification:** The native Swift codebase in `AcademicOS/` remains clean, untouched, and ready for macOS compilation and Xcode execution.
- **Zero SQLite Modification:** The production database schema and records are not touched; the preview environment relies on an isolated mock engine.
- **Clean Separation:** All preview assets reside exclusively inside `UI-Preview/`:
  - `UI-Preview/server.js`: Static HTTP server with mime detection.
  - `UI-Preview/index.html`: Responsive iPhone 16 Pro viewport shell.
  - `UI-Preview/styles.css`: Apple Human Interface Guidelines design tokens, dark/light themes, and animations.
  - `UI-Preview/app.js`: Interactive state machine and mock data engine.
